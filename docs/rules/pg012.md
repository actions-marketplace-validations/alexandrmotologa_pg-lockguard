# PG012: Direct DROP TABLE or DROP COLUMN

## Lock Level Acquired
`ACCESS EXCLUSIVE`

## Problem
Dropping a table or column takes an instant ACCESS EXCLUSIVE lock and permanently deletes the schema element, breaking any active queries that have not yet refreshed.

## Dangerous Pattern
```sql
ALTER TABLE users DROP COLUMN phone;
```

## Safe Zero-Downtime Recipe
```sql
-- 1. Mark column as ignored in application ORM models
-- 2. Deploy updated application servers
-- 3. Run DROP COLUMN migration after observing zero traffic to that column:
ALTER TABLE users DROP COLUMN IF EXISTS phone;
```
