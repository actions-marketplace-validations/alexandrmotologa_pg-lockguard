# PG009: Concurrent DDL in Explicit Transaction

## Lock Level Acquired
`SHARE_UPDATE_EXCLUSIVE`

## Problem
PostgreSQL does not permit concurrent operations like CREATE INDEX CONCURRENTLY or DROP INDEX CONCURRENTLY inside multi-statement transaction blocks (BEGIN ... COMMIT).

## Dangerous Pattern
```sql
BEGIN;
CREATE INDEX CONCURRENTLY idx_users ON users (id);
COMMIT;
```

## Safe Zero-Downtime Recipe
```sql
-- Remove BEGIN / COMMIT wrappers for concurrent migrations:
CREATE INDEX CONCURRENTLY idx_users ON users (id);
```
