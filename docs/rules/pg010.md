# PG010: ADD CHECK Constraint without NOT VALID

## Lock Level Acquired
`ACCESS EXCLUSIVE`

## Problem
Adding a CHECK constraint without NOT VALID locks the table for full sequential validation across all existing rows under an ACCESS EXCLUSIVE lock.

## Dangerous Pattern
```sql
ALTER TABLE users ADD CONSTRAINT chk_age CHECK (age >= 18);
```

## Safe Zero-Downtime Recipe
```sql
-- Step 1: Add constraint with NOT VALID (instant metadata lock)
ALTER TABLE users ADD CONSTRAINT chk_age CHECK (age >= 18) NOT VALID;

-- Step 2: Validate constraint in a separate transaction
ALTER TABLE users VALIDATE CONSTRAINT chk_age;
```
