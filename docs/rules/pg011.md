# PG011: Direct Column or Table Rename

## Lock Level Acquired
`ACCESS EXCLUSIVE`

## Problem
Renaming a column or table acquires an ACCESS EXCLUSIVE lock and immediately breaks active in-flight application queries referencing the previous identifier.

## Dangerous Pattern
```sql
ALTER TABLE users RENAME COLUMN first_name TO given_name;
```

## Safe Zero-Downtime Recipe
```sql
-- Use the expand/contract pattern:
-- 1. Add 'given_name' column
-- 2. Dual-write to both columns
-- 3. Deploy updated application code reading from 'given_name'
-- 4. Drop 'first_name'
```
