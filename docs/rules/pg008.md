# PG008: VACUUM FULL or CLUSTER Statement

## Lock Level Acquired
`ACCESS EXCLUSIVE`

## Problem
VACUUM FULL and CLUSTER rewrite entire tables to disk while holding an ACCESS EXCLUSIVE lock, blocking all concurrent reads and writes for the entire duration.

## Dangerous Pattern
```sql
VACUUM FULL users;
```

## Safe Zero-Downtime Recipe
```sql
-- Routine maintenance (non-blocking vacuum):
VACUUM (ANALYZE) users;

-- Online table repacking without exclusive locks:
-- Use external utility pg_repack instead.
```
